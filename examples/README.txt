# Sample Room Photos

This folder contains high-resolution open-source room photos (Creative Commons / Wikimedia Commons) for testing and demonstration:

- `room.jpg` / `living_room.jpg`: A classic living room ready for renovation. (Living Room in Henderson House, CC BY-SA)
- `bedroom.jpg`: A residential bedroom with natural window light. (Bedroom Mitcham, CC BY-SA)
- `kitchen.jpg`: A dated kitchen layout suitable for modern remodeling. (Alno Küchenzeile, CC BY-SA)

You can run renovation directly using:
```bash
renovate run --image examples/room.jpg --style japandi
renovate run --image examples/bedroom.jpg --style scandinavian
renovate run --image examples/kitchen.jpg --style modern
```

Or drop any of your own photos here.
